# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes, detects skills,
provides AI-generated feedback, and compares resumes with job
descriptions using ATS-style matching.

## 🚀 Live Demo

[https://YOUR-APP-URL.streamlit.app](https://ai-resume-analyzer-fwpycck3rtpdcbwjbbvtfs.streamlit.app/)

## ✨ Features

- 📄 Upload resume in PDF format
- 🧑‍💻 Automatic skill detection
- 📊 Resume score
- 🤖 AI-powered resume feedback
- 🎯 ATS match score
- 🔍 Matching skills detection
- ❌ Missing skills and keywords
- 💡 Resume improvement suggestions
- 📥 Downloadable PDF analysis report
- 🌐 Deployed as a web application

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- PyPDF
- ReportLab
- Regular Expressions
